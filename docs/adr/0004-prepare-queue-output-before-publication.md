# Prepare queue output before publication

Render publication rules in the queue channel after ingestion so the admin can inspect the post that will be delivered. Preserve original attribution metadata independently of prepared output, and freeze each new item's forwarding mode at enqueue (at rollout for legacy items): later repostable-channel changes affect new enqueues because a copied post cannot reliably regain its original forwarding header. Nickname changes refresh untouched generated bylines before waiting posts become eligible for publication; intentional admin edits and removals take precedence and must survive preparation, refresh, renewal, and publication.
