# Freeze the whole post after admin edits

Any admin edit to a current queue message permanently freezes its whole logical post, including album members and a separate credit. Adopt an edited raw submission as shown; later nickname changes must not rewrite any part of it, and renewal/publication must preserve that representation. This deliberately gives up automatic nickname freshness for the entire post, even when only the body or one album member changed, because keeping the admin's final editorial control is more important than preserving bot ownership of an untouched credit. Protection survives replacement sources and restart. If a previously initiated remote edit collides with an admin edit, stop automatic work and require review without another bot rewrite; local guards cannot revoke an already-initiated Telegram request.
